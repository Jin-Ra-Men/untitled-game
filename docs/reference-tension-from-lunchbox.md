# 레퍼런스 분석: 「도시락 데우기」에서 뽑는 긴장·방향성

> **영상:** [총성과 다이아몬드 — 보너스 에피소드. 도시락 데우기](https://youtu.be/CpusF__84SU) (PuppleStorm)  
> **원작 위치:** 전 엔딩 수집 후 해금되는 보너스 교섭. 편의점 알바 행세하는 사와다에게 **도시락을 데워 달라**고 부탁하는 IF 장면.  
> **용도:** IP 복제용이 아님. **긴장 설계·톤 레시피**만 이 프로젝트(영세 게임사 HR 생존기)에 이식한다.

---

## 1. 영상이 보여주는 핵심

원작 본편 교섭은 인질·총·목숨이 걸린다. 이 보너스는 목표만 **전자레인지**로 바뀌고, 시스템·UI·실시간 압박·흥분 게이지는 **그대로**다.

→ 코미디의 원천은 “개그 선택지”가 아니라 **진지한 교섭 기계 × 하찮은 목적**의 미스매치다.  
→ 이 프로젝트의 **고통의 코미디**와 1:1로 맞는다. 스테이크는 인질이 아니라 **전환 점수·팀장 눈치·체면**이면 충분하다.

---

## 2. 원작에서 가져올 긴장 레시피 (시스템 감성)

복제하지 말고 **규칙으로 재구현**할 것.

| 레시피 | 원작에서의 느낌 | 미제에서의 이식 |
|--------|-----------------|-----------------|
| **실시간 창** | 상대가 2–3문장 말하는 동안 커맨드가 뜨고, 늦으면 강제 선택·소멸·흥분 | 전화/화상/책상 앞 대화도 “시간이 흐르는 말”로 진행. 멈춘 메뉴판 VN 금지 |
| **침묵·경청·끼어들기** | 커맨드를 다 쓸 필요 없음. 안 말하는 게 유리한 구간 존재 | 면접·서류 독촉에서도 **침묵 = 유효 입력**. 난사하면 파탄 |
| **흥분/인상 게이지** | 라이프에 가깝고, 한 방에 절반·풀충전 가능. 상대마다 트리거 다름 | `인상`·`협조`·`꼰대 게이지` 등으로 치환. **역린 한 방** 유지 |
| **일부러 자극** | 흥분을 올려야 단서·좋은 결과가 나오는 상대도 있음 | 팀장 달래기 ≠ 항상 저자극. “한 번 빡치게 한 뒤 수습” 루프 허용 |
| **프로파일 → 선택 힌트** | 키워드 분석 성공 시 선택지에 +/- 표시. 실패해도 교섭은 가능 | HR 프로파일 성공 시 함정/유효 선택 표시. 실패 = 보너스 없음일 뿐 |
| **오디오가 보이스** | 풀더빙 없이 OST·SE가 긴장 곡선 담당 | 프로토타입부터 **짧은 압박 BGM/틱**으로 실시간감 검증 |
| **파탄 후 직전 재시도** | 교섭 결렬 → 교섭 직전부터 다시 | 학습형 난이도. “한 번에 완벽” 강요로 이탈시키지 않음 |
| **강약 호흡** | 진지 사건 사이 만담·꽁트로 풀었다 조였다 | D-30 스파인 안에 **하찮은 교섭**(전자레인지·도장·슬랙 읽씹)과 **고스테이크 교섭**(평가·전환)을 교차 |

## 3. 「도시락 데우기」가 미제에 주는 방향성

### 3.1 스테이크 미스매치 (확정 지향)

- **객관적 사안**은 작아도 된다: 가족관계증명서, 전자레인지 줄, 결재 도장, “오늘 중 PDF”.
- **플레이어 비용**은 크게: 전환 심사 한 줄, 팀장 escalate, 파벌에 찍힘, 체면.
- 연출·UI는 인질극처럼 진지하게. 대사가 웃기면 웃기되, **시스템이 개그로 풀리지 않게**.

### 3.2 하찮은 교섭 = 본편 루프의 축소판

보너스 에피소드처럼 “정신 나간 교섭”을 **본편 호흡 조절용 단편**으로 쓴다.

예 (오리지널, 원작 고유명·설정 금지):

- 크런치 중 **전자레인지 줄**에서 시니어에게 양보받기  
- 경영진 미팅 전 **결재 도장** 받기  
- 슬랙 읽씹하는 입사예정자에게 **서류 한 장** 받아내기 ← 현재 테스트 에피소드와 동일 계열

### 3.3 긴장감이 나오는 조건 (프로토타입 체크리스트)

1. 대화가 **실시간으로 흘러가는가** (대기만 하는 선택지 UI가 아닌가)  
2. **침묵/끼어들기**가 실제로 결과 차이가 나는가  
3. **역린 한 방**이 있고, 그게 독성 개그로 플레이어에게 “보상”되지 않는가  
4. 성공해도 **팀장 칭찬 없이** 생존·체크리스트·미세 점수만 주는가 (도시락을 데워도 세상은 안 바뀜)  
5. 실패 시 **즉시 재시도**로 학습이 되는가
