# 프로젝트 컨텍스트 (미제)

PC용 신작 게임. 작업명은 **미제**(untitled). 사용자: 진 이.

## 목표

2009년 소니( SCE ) 계열로 출시·유통된 『총성과 다이아몬드』의 **콘셉트**를 채용해, PC에서 즐길 수 있는 새 게임을 만든다.  
원작 IP의 리메이크·클론이 아니라, 핵심 판타지·시스템 감성·톤에서 **영감**을 받는 오리지널 작품이다.  
설정은 **영세 게임사 인사팀 인턴의 정규직 전환 생존기**로, PSP 범죄 교섭 어드벤처의 리메이크가 아니다.

## 플랫폼

- **PC 게임** (확정)

**매칭 신뢰도: 매우 높음.** 한국 공식 한글 타이틀이 그대로 「총성과 다이아몬드」이며, 2009년 소니 출시·PSP라는 조건과 일치한다. 동명·유사명의 다른 소니 타이틀은 확인되지 않았다.

### 원작의 핵심 판타지

근미래 도쿄. 흉악 범죄에 대응하기 위해 구성된 특수팀(제로과)의 **민간 교섭 전문가**가 되어, 인질·특수 범죄 현장에서 범인과 심리전을 벌이며 사건을 풀어 나간다. 단편 에피소드가 점차 하나의 큰 음모로 수렴한다.

### 시그니처 시스템·톤 (콘셉트 채용 시 참고)

- **실시간 교섭**: 대화가 시간에 따라 흐르며, 선택·침묵·끼어들기·타이밍이 결과에 영향
- **프로파일링**: 수사·정보 수집으로 범인상을 파악한 뒤 교섭에 반영
- **에피소드형 서사**: 사건 단위로 진행되다가 후반에 연결
- **톤**: 하드보일드에 가까운 범죄 스릴러·심리전 (연애 중심 VN이 아님)

### 원작과의 거리 (확정 방향)

- **영감**: 실시간 교섭·프로파일링·에피소드 구조·긴장 톤
- **오리지널**: 세계관·직업·스토리 — 꼰대·독성 영세 게임사에서 인사팀 인턴이 정규직 전환을 위해 고군분투. 원작 캐릭터·고유명·설정·에셋·시나리오는 복제하지 않음
- “공식 후속/리메이크” 포지셔닝 없음

### 직장 루프로의 시그니처 매핑 (초안)

- **실시간 교섭** → 면접·면담·팀장 달래기·평가 시즌 자리에서 타이밍·침묵·끼어들기가 인상·결과를 좌우
- **프로파일링** → 팀장·개발·기획·경영진의 성향·약점·파벌·꼰대 트리거를 파악해 교섭·대응에 반영
- **에피소드형 서사** → 채용 한 건·팀 갈등·평가 시즌·경영진 압박 같은 HR 위기 단위가 정규직 전환 D-30으로 수렴
- **긴장 톤** → 인질극 대신 **평가·정치·시한·독성 조직문화**가 압박을 만드는 직장 스릴러 (고통의 코미디 감성 유지)

인사팀 인턴 시점에서는 “현장 인질” 대신 **사람·평가·정치**가 교섭 대상이다. 채용 면접 중 팀장 설득, 면담에서 꼰대 상사 달래기, 평가 시즌에 누가 누구를 밀어주는지 프로파일하는 장면이 원작의 실시간 교섭·프로파일링과 1:1로 맞물린다.

### 레퍼런스 플레이 분석 → 긴장·방향성 (추가)

플레이 레퍼런스: [보너스 에피소드 「도시락 데우기」](https://youtu.be/CpusF__84SU) (원작 클리어 특전 교섭).  
상세 레시피·체크리스트 → `docs/reference-tension-from-lunchbox.md`

**한 줄 교훈:** 목표는 전자레인지여도 교섭 UI·실시간·흥분 게이지는 인질극과 같다. 코미디는 시스템을 농담으로 풀어서가 아니라 **진지한 기계 × 하찮은 목적**에서 나온다.

이 프로젝트에 고정할 방향:

1. **스테이크 미스매치** — 사안(서류·도장·전자레인지 줄)은 작아도, 플레이어 비용(전환·팀장·체면)은 크게.
2. **시스템 진지성** — 멈춘 선택지 VN이 아니라 시간이 흐르는 말; 침묵·끼어들기가 유효 입력.
3. **역린·게이지** — 상대별 금기 한 방; 인상/협조 게이지는 라이프에 가깝게.
4. **강약** — 고스테이크(평가·전환)와 하찮은 교섭(생존 코미디 단편)을 D-30 안에 교차.
5. **재시도 친화** — 파탄 시 교섭 직전 리스타트로 학습 루프.

테스트 에피소드(가족관계증명서)는 이미 이 레시피의 본편형이다: 사안은 서류 한 장, 비용은 전환 심사.

## 확정된 결정

1. PC 게임으로 제작한다.
2. 레퍼런스는 『총성과 다이아몬드』(2009, SCE/PSP)이며, **콘셉트 영감**이다 (리메이크·IP 복제 아님).
3. 작업명은 당분간 **미제**.
4. **엔진**: Unity (2D, C#).
5. **표현**: 2D.
6. **산업·회사**: 게임 회사. 진짜 심한 **꼰대·권위주의·독성 조직문화의 좆소기업급 영세 게임사** 감성 (고통의 코미디; 평범한 ‘힘든 직장’으로 희석하지 않음).
7. **주인공**: 인사팀(HR) 인턴.
8. **메인 시나리오 스파인**: 정규직 전환 심사가 **한 달**(D-30) 남은 시점에서, 어떻게든 정규직으로 전환되기 위해 고군분투한다.
9. 설정은 오리지널(영세 게임사·HR 인턴 생존기). 원작 거리 = 시스템·톤 영감 / 세계관·직업·스토리 오리지널.

## 미결정 (오픈 퀘스천)

- **톤·수위 디테일**: 독성·괴롭힘·권위주의 표현의 구체 수위, 유머 vs 암울 비중, 대상 연령대 (조직문화 방향 자체는 확정)
- **에피소드 수**: 한 달 스파인 안에서의 단편(면접·면담·팀 갈등·평가 시즌 등) 개수
- **멀티엔딩**: 전환 성공/실패/회색 엔딩 비중과 분기 깊이
- **회사 디테일**: 구체 사명·출시작·규모 수치·캐릭터명 (업종·독성 영세 감성은 확정)
- **싱글/온라인**: 현재는 싱글 플레이 전제; 멀티는 논의된 바 없음

## 테스트 에피소드 후보 (확정)

- **가족관계증명서**: 입사예정자에게 빠진 온보딩 서류(가족관계증명서)를 받아내는 실시간 교섭 장면. 텍스트 전용 초안 → `docs/test-episode-family-certificate.md`

## 디자인 킥오프 다음 단계

1. 오픈 퀘스천 중 **톤·수위 디테일, 에피소드 수·멀티엔딩, 회사 디테일**을 우선 확인한다.
2. 원작 시그니처 → HR·독성 게임사 교섭/평가 루프 매핑을 플레이 가능한 규칙으로 고정한다. 긴장 레시피는 `docs/reference-tension-from-lunchbox.md`를 기준으로 한다.
3. 프로토타입: 가족관계증명서 교섭 Core가 코드로 들어감 (`Assets/Scripts/Negotiation/`, `dotnet run --project tools/Playtest`). 다음: Unity 에디터에서 UI·연출 다듬기 + 톤 검증.
