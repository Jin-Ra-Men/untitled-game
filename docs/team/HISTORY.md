**시간순(오래된 것 → 새것)** — 새 줄은 **맨 아래**에 append. 중간에 끼워 넣지 말 것.

`MEMORY.md`(교훈)와 다름. 여기는 **무슨 일을 했는지** 짧은 이력만.

## 형식

```text
- YYYY-MM-DD HH:MM · (역할) · `task-id-또는-없음` · 한 줄 요약
```

- 시각: 로컬(한국) 24시간제. 분까지. 불명확하면 쪽지/파일명의 시각 사용.
- 역할: `leader` / `docs` / `worker` / `design` / `review` / `human` / `team`
- task-id: queue 폴더명. 없으면 `-`
- 한 줄: 무엇을 배정·완료·통과·반려·종료했는지. 장문 금지.
