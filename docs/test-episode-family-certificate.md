# 테스트 에피소드: 가족관계증명서

> **라벨:** 테스트 에피소드 (풀 캠페인 아님) · **포맷:** 텍스트만 / 인터랙티브 픽션 초안  
> **플레이 목표:** 입사예정자에게 **가족관계증명서**를 받아낸다.  
> **플레이 시간:** 한 번에 읽히는 분량 (소설 아님)  
> **이름:** 플레이스홀더 — 확정 전

---

## 0. 셋업 (짧게)

당신은 **인사팀 인턴**. 정규직 전환 심사 **D-23**.  
회사는 좆소기업급 영세 게임사. 팀장 **박팀장**(가칭)은 “서류 하나 못 받으면 인턴이 뭐 하냐” 타입이다.

오늘 업무: 내일 입사식 전, 입사예정자 **한민재**(가칭, 20대 후반 / “MZ입사예정자” 타입)에게 빠진 온보딩 서류를 받아라.  
빠진 것: **가족관계증명서**. 민재는 “집 어딘가에 있을 것 같은데요?” 수준으로 잊었다.

**스테이크**
- 성공 → 팀장 눈치 ↓, 전환 심사에 ‘일 처리’ 한 줄 가능  
- 애매 → 서류는 오는데 기한·태도 이슈로 팀장에게 한소리  
- 실패 / 팀장 escalate → “인턴이 사람 하나 못 다루냐”로 전환 점수 깎임

---

## 1. 프로파일 (선택적으로 “안다”)

플레이어가 교섭 전·중에 열어볼 수 있는 짧은 정보. (전부 알 필요는 없음)

**한민재 (입사예정자)**
- 서류 메일 3번 중 2번 읽씹. 답장은 “넵ㅋㅋ” 위주.
- “집 가면 찾을게요”를 이미 어제로 미룸.
- 자존심: 본인을 ‘대충하는 사람’으로 규정당하는 걸 싫어함. (실수는 인정해도 성격 공격은 튕김)
- 약점: 내일 입사식 사진·명찰·슬랙 초대가 필요함. HR이 막고 있으면 불안해짐.
- 트리거: “MZ는 원래 이래” / “요즘 애들은” → 방어·비꼼 모드.
- 약점2: 어머니에게 서류 부탁하면 바로 나올 가능성 높음. 다만 “부모님 호출” 티가 나면 창피해함.

**박팀장 (HR)**
- “결과만 가져와.” 과정 설명 = 변명으로 들림.
- 오늘 15:30 경영진 미팅. 그 전에 서류 체크리스트를 닫고 싶어함.
- escalate 시: 민재에게 직접 전화 → 민재 불쾌 + 인턴 무능 프레임.

**시계 (실시간 압박용)**
- 지금 **14:10**. 팀장 미팅 **15:30**.  
- 민재와 화상/전화 교섭 창: 대략 **12~15분**. 끌면 민재가 “나중에”로 끊을 수 있음.

---

## 2. 오프닝 비트

**(사무실. 박팀장이 모니터도 안 보고 말함.)**

**박팀장:** 한민재. 가족관계증명서. 내일까지. 아니, **오늘**까지.  
**박팀장:** 인턴이 연락해. 나 미팅 전에 체크리스트 닫을 거니까.  
**박팀장:** …뭐? “집 어딘가”라고? 그거 네 문제야. 가서 받아와. *(자리를 뜸)*

**(선택 — 교섭 전)**
- **A.** 프로파일만 훑고 바로 연락한다.  
- **B.** 슬랙으로 “서류 리스트 + 제출 링크”만 먼저 보낸다. (시간 −2분, 민재 준비도 ↑)  
- **C.** 팀장에게 “기한 내일 아침으로” 한 번 물어본다. → **거절 + 눈치 ↑**. 시간 −1분.

→ 기본 경로: **전화/화상 교섭**으로 진입.

---

## 3. 교섭 본편 — 실시간 비트

> 표기: `[⏱]` = 시간 흐름 / **선택** · **침묵** · **끼어들기**  
> 내부 수치(프로토타입용, 화면에 안 보여도 됨): `협조 0~3` · `자존심 −2~+2` · `시한` (여유/촉박/마감임박)

### Beat 1 — 연결 (⏱ 약 1분)

**한민재:** 어, 안녕하세요? 저 지금 카페인데요. 입사 관련이죠?

| 입력 | 대사/효과 |
|------|-----------|
| **선택 A** “가족관계증명서만 남았어요. 오늘 중으로 주세요.” | 명확. `협조 +0`, `시한→촉박` 인식시킴. |
| **선택 B** “민재님 입사 준비 잘 되고 계세요?” (스몰톡) | `자존심 +1`, 시간 −1분. 본론 늦어짐. |
| **침묵** (2초 이상) | 민재: “…여보세요?” `협조 −1` if 침묵 과함. |
| **끼어들기** (민재가 “카페에서—” 말할 때) “서류부터요.” | `협조 +1` or `자존심 −1` (톤에 따라). 빠르면 성공 쪽. |

**한민재 (기본 반응):** 아 그거… 집에 있을 건데, 지금 밖에 있어서요. 내일 들고 가면 안 돼요?

---

### Beat 2 — 변명 구간 (⏱ 약 3분) · **시간압박 핵심**

민재가 말을 늘인다. 플레이어가 **끼어들지 않으면** 시계가 간다.

**한민재:** 이거 인터넷으로도 되죠? 근데 공동인증서가… 아 맞다 폰 바꿨는데—  
**한민재:** 그리고 어제 메일은 봤는데, 첨부 리스트가 길어서 그냥… 스크롤하다가—

| 입력 | 결과 힌트 |
|------|-----------|
| **침묵** (민재가 끝까지 말하게 둠) | 정보(“폰 바꿈”) 획득. 시간 −2분. `협조` 변화 없음. |
| **끼어들기** “정부24로 바로 발급 돼요. 카페에서도요.” | `협조 +1`. 실무 루트 개방. |
| **선택** “내일은 팀장님이 안 받아요. 오늘이요.” | 압박. `협조 +1`, `자존심 −1`. |
| **선택 (프로파일: 트리거 주의)** “MZ분들은 서류를 잘 안 보시더라고요.” | **실패 쪽 가속.** `자존심 −2`, `협조 −1`. 민재 비꼼 모드. |

**민재 비꼼 모드 예시:** “와 첫날부터 세대론이세요? ㅋㅋ 서류는 찾을게요. 태도 문제는 아닌 것 같은데요.”

---

### Beat 3 — 거래 (⏱ 약 4분)

목표: **오늘 제출**을 민재가 스스로 납득하거나, 체면 살려 주며 움직이게 한다.

**한민재:** 그러면… 저녁에 집 가서 찾아서 내일 아침에 찍어서 보내면요?

| 입력 | 분기 |
|------|-----------|
| **선택 A — 실무** “지금 정부24 → 가족관계증명서 → PDF. 제가 링크 다시 보낼게요. 5분이면 됩니다.” | `협조` 높으면 **최소 성공** 루트. |
| **선택 B — 체면** “잊으신 거 누가 알겠어요. 저만 체크리스트 닫으면 끝이에요.” | `자존심 +1`, `협조 +1`. 성공 확률 ↑. |
| **선택 C — 압박** “안 오면 입사식 명찰·슬랙 보류예요.” | 프로파일 약점 사용. `협조 +2` but `자존심 −1`. **애매** 위험(나중에 팀장에게 불만 제기). |
| **선택 D — 부모** “어머니께 부탁하시면 제일 빨라요.” | 효과는 큼. 민재가 창피하면 거부. `자존심` 낮으면 **실패/지연**. |
| **침묵** | 민재: “……그럼 저녁에 할게요.” → **애매/실패** 쪽으로 미끄러짐. |
| **끼어들기** (민재가 “내일 아침” 말할 때) “아침이면 팀장 미팅 지나가요.” | 시간 압박 재강조. `협조 +1`. |

---

### Beat 4 — 클로징 / 마감임박 (⏱ 남은 시간 < 3분 또는 팀장 슬랙 알림)

**(선택적 이벤트)** 박팀장 슬랙: `한민재 서류. 미팅 전. 답만.`

| 입력 | 결과 |
|------|------|
| **선택** 민재에게 사실대로 “팀장이 지금 재촉 중” | 솔직. `협조 +1` if 관계 괜찮음. 아니면 민재가 “저한테 화풀이하지 마세요.” |
| **선택** 팀장에게 “받는 중”만 회신, 민재 교섭 계속 | 시간 관리. 안전. |
| **끼어들기 실패** (당황해서 팀장·민재 동시 대응) | 말 꼬임 → **팀장 escalate** 위험. |
| **침묵** (슬랙 읽씹) | 팀장 직접 민재 연락 → **escalate 엔딩**. |

## 4. 분기 아웃컴 (최소 3종)

### ★ 최소 성공 — “PDF 입고”

조건 예: `협조 ≥ 2`, 트리거 대사 안 씀, Beat 3에서 실무/체면 루트.

- 민재가 카페에서 발급 → 메일/폼 제출.  
- 팀장: “됐어.” (칭찬 없음. 그래도 체크리스트 닫힘.)  
- **전환 심사:** ‘온보딩 클로징’ 작은 플러스.  
- 엔딩 한 줄: *서류는 왔다. 자존심 상한 신입은 아직 안 왔다. 그건 내일 문제다.*

### ◆ 애매 — “오긴 왔는데”

조건 예: 압박(명찰 보류) 과다, 또는 “저녁에 집” 합의 후 밤늦게 도착.

- 서류는 **오늘 23:40** 도착. 팀장 미팅에는 못 씀.  
- 팀장: “미팅 전에 하라고 했지. 인턴 일정 감각이…”  
- 민재는 제출했지만 HR에 감점 감정 남음.  
- **전환 심사:** 플러스·마이너스 상쇄. 다음 에피소드에 팀장 눈치 잔여.

### ✗ 실패 — “내일 들고 갈게요” 확정

조건 예: 침묵 과다, 스몰톡만, 또는 트리거(“MZ”) 발동 후 수습 실패.

- 민재 종료: “내일 입사할 때 지참할게요. 끊을게요.”  
- 체크리스트 미닫힘.

### ✗✗ 팀장 escalate

조건 예: 슬랙 무시, 교섭 시간 초과, 동시 대응 실패.

- 박팀장이 민재에게 직접 전화. 민재 불쾌.  
- 팀장 → 당신: “내가 왜 신입한테 전화하냐. 너 전환 때 이 얘기 나온다.”  
- **전환 심사:** 명확 마이너스.  
- 엔딩 한 줄: *서류는 팀장이 받아냈다. 네 체면도 같이 가져갔다.*

## 5. 프로토타입 메모 (구현 전 텍스트 검증용)

- **톤 레퍼런스:** 원작 보너스 「도시락 데우기」([영상](https://youtu.be/CpusF__84SU)) — 사안은 하찮고(서류 한 장), 교섭 기계는 진지. 상세 → `docs/reference-tension-from-lunchbox.md`
- 검증 포인트: **끼어들기 타이밍**이 “말 자르기”가 아니라 **변명 루프 차단**으로 느껴지는지.  
- 프로파일 ‘세대 트리거’는 **함정(역린)**으로 둘 것 — 독성 코미디지, 플레이어에게 혐오 대사 보상이 되면 안 됨.  
- 성공해도 팀장 칭찬은 없음. 보상은 **생존·체크리스트·전환 점수 미세 상승** (도시락을 데워도 세상은 안 바뀜).  
- 실패 시 **교섭 직전 재시도**가 학습으로 느껴지는지 (이탈용 벽이 아닌지).  
- 다음 테스트로 확장 가능: 민재가 PDF는 냈는데 **주민등록등본과 혼동**한 서브 비트 (옵션, 본 에피소드엔 넣지 않음).
