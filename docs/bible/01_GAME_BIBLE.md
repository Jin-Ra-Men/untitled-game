## 한 줄 정의

영세 게임사 인사팀 인턴의 **정규직 전환 D-30 생존기**. 직장 스릴러 + 고통의 코미디.

---

## 장르 · 타깃 · 플레이

| 항목 | 결정 |
|------|------|
| 장르 | **내러티브 어드벤처** (실시간 교섭이 핵심 루프) |
| 타깃 플레이어 | 서브컬처·스토리 게임을 좋아하는 **PC** 이용자 |
| 플레이어가 하는 일 | 스토리를 보다가 **리얼타임 협상**이 열리면 선택지(·침묵)로 원하는 결과를 뽑아낸다 |
| 핵심 재미 | **비협조적인 상대**와 리얼타임 협상으로 원하는 결과를 얻는 것. 주인공↔상대의 **밀고 당기는 긴장** |
| 예상 플레이타임 | **5~6시간** |
| 최종 목표 | **정규직 전환** |

스토리 구간은 진행·연출 중심이고, 재미의 정점은 협상 구간이다. 협상은 멈춘 메뉴판이 아니라 시간이 흐르는 밀당이다.

---

## 기둥 (Pillars)

1. **실시간 교섭** — 시간이 흐르는 말; 선택·침묵·**끼어들기**·타이밍이 결과.
2. **프로파일링** — 팀장·개발·기획·경영진의 성향·파벌·역린을 파악해 대응에 반영.
3. **에피소드형 서사** — HR 위기 단편이 D-30으로 수렴.
4. **스테이크 미스매치** — 사안(서류·도장)은 작아도, 플레이어 비용(전환·팀장·체면)은 크게.
5. **진지한 기계 × 하찮은 목적** — 코미디는 시스템을 농담으로 풀어서가 아니라 미스매치에서 나온다.

## 하지 말 것

- 원작 인질·제로과·범죄 현장·고유명·설정 복제
- 연애 중심 비주얼 노벨로 흐르기 (귀여움은 포장, 압박은 직장 정치)
- 멈춘 메뉴판 VN (시간·침묵이 무의미한 선택지만)
- 플레이어 문자열을 C#에 하드코딩
- 미결정 항목(톤 수위, 에피소드 수·배치, 멀티엔딩 깊이, 회사명·캐릭터명)을 임의 확정
- 핵심 재미를 “스토리만 보기” 또는 “연애 공략”으로 바꾸기 (스토리는 뼈대, 재미는 리얼타임 밀당 협상)

## 긴장 레시피 (요약)

1. 사안은 작아도 됨 / 플레이어 비용은 크게  
2. 시간이 흐르는 말; 침묵·끼어들기 = 유효 입력 (창·타이밍)  

3. 상대별 **역린 한 방**; 협조/자존심 게이지는 라이프에 가깝게  
4. 고스테이크와 하찮은 생존 교섭을 교차  
5. 파탄 시 교섭 직전 재시도 (학습 루프)

테스트 에피소드(가족관계증명서)가 본편형 레시피의 첫 구현이다.
